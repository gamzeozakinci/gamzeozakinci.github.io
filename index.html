05Projects

Gratis.com — Playwright + TestNG UI Automation

End-to-end UI test automation for gratis.com, a large Turkish cosmetics e-commerce site. 30 test cases across authentication, navigation, search, filtering, product pages, wishlist, cart and checkout, written in Java with Playwright and TestNG using the Page Object Model. It runs against the real, live site, so much of the work went into making tests reliable against a production front end: OTP-only login, look-alike elements, flaky clicks and a third-party payment widget.

  • 30 test cases
  • 7 areas
  • 3 suites
  • 6 smoke tests
  • Login without automating the OTP: a one-time manual capture saves the session cookies with Playwright's storageState, and logged-in tests start already authenticated (the token lasts about 15 minutes)
  • Reliable locators: web-first assertions and auto-waiting instead of sleeps, and locators scoped to one product card, cart row or dialog, since the same element often appears several times on the page
  • Retry with verification for genuinely flaky actions, confirming the result of a click before continuing
  • Full regression, tagged smoke and manual auth suites; desktop and mobile viewports; failure screenshots and TestNG HTML report
  • Checkout stops when the payment step opens: no test card, no real order on the live site
